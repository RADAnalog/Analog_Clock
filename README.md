# Analog_Clock

Placeholder for my analog clock project.  The project uses analog volt meters for the display of hours, minutes and seconds.

The meters used are low cost (from China), and require a degree of crafty work to print and attach new scale labels.  Some meter case modification is needed to add an LED backlight.
